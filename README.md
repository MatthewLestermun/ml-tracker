# ML Трекер — жизнь как игра_

Личный трекер для челленджа: привычки, задачи, клиенты и деньги — с уровнями, XP и достижениями.
Работает на телефоне как приложение (PWA), данные хранятся только на твоём устройстве.

## Что умеет

- **Привычки** — отметки за день, кольцо прогресса, серия дней, сетка всего челленджа
- **Задачи** — срок, приоритет, категория, фильтры «Активные / Сегодня / Готово»
- **Клиенты** — мини-CRM: этапы от «Нашёл» до «Оплачено», воронка с конверсией, напоминания «когда написать»
- **Деньги** — доходы и расходы, прогресс к цели, прогноз по темпу
- **Уровень** — XP, звания, достижения, резервная копия данных
- Выгрузка таблиц в Excel (CSV)

## Как поставить на телефон

1. Открой ссылку на трекер в браузере телефона
2. **Android (Chrome):** меню ⋮ → «Добавить на главный экран»
   **iPhone (Safari):** «Поделиться» → «На экран „Домой“»
3. При первом запуске введи имя, дату старта, цель и количество дней

Данные живут в браузере конкретного устройства. Чтобы ничего не потерять — раз в неделю жми «Сохранить копию» на вкладке «Уровень».

## Технологии

Чистые HTML, CSS и JavaScript — без фреймворков и сборщиков. localStorage для данных, Service Worker для работы без интернета.
